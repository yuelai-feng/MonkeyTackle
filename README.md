# MonkeyTackle: A retractor designed for (NHP) chamber implant surgery
---
MonkeyTackle is a retractor designed for stereotaxic chamber implant surgeries in NHPs. It is extremely low-profile, self-retaining, and allows for retraction in all directions.

## How to build your 
* Screws (M5, 10mm long): https://www.mcmaster.com/92625A309/
* Blunt hooks (~5-8mm diameter)
* Suture (size 2, braided, no needle)
