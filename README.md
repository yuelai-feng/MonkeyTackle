# 🎣 MonkeyTackle: a retractor for chamber implant surgeries

MonkeyTackle is a retractor designed for stereotaxic chamber implant surgeries in NHPs. It is extremely low-profile, self-retaining, and allows for retraction in all directions.

A MonkeyTackle retractor consists of:

* a blunt skin hook, which hooks onto the skin margin;
* a thin string tied to the skin hook; and
* a holder, clamped onto the stereotax arm over the surgical drape and holds the string in place
